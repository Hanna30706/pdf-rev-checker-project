# JSON 구조 상세 분석 보고서

## 📋 개요

**PDF 파일**: `[I-AGG-0301-030-A01]부표1. 현장점검 수행 및 평가기준_개정 전.pdf`

**생성된 JSON 파일**: `*_structured.json`

이 문서는 생성된 JSON 파일의 **페이지 1의 모든 요소**를 상세 분석한 것입니다.

---

## 🗂️ JSON 최상위 구조

```json
{
  "metadata": {
    "filename": "string",           // PDF 파일명
    "total_pages": number,          // 총 페이지 수
    "file_size_kb": number,         // 파일 크기 (KB)
    "extraction_type": "structured" // 추출 유형
  },
  "content": [
    {
      "page_num": 1,
      "width": 595.0,    // 페이지 너비 (포인트)
      "height": 842.0,   // 페이지 높이 (포인트)
      "elements": [...]  // 요소들
    },
    ...
  ]
}
```

## 📌 ELEMENT 1: HEADING (제목)

### JSON 구조

```json
{
  "type": "heading",
  "page_num": 1,
  "bbox": [70.70, 312.86, 524.30, 349.69],
  "text": "부표1. 현장점검 수행 및 평가기준",
  "font_size": 32.02,
  "is_bold": true,
  "line_count": 1
}
```

### 상세 분석

| 속성 | 값 | 설명 |
|------|-----|------|
| **type** | `"heading"` | 요소 타입: 제목 |
| **page_num** | `1` | 페이지 번호 |
| **bbox** | `[70.70, 312.86, 524.30, 349.69]` | 좌표 정보 |
| **text** | `"부표1. 현장점검 수행 및 평가기준"` | 제목 텍스트 |
| **font_size** | `32.02` | 폰트 크기 (포인트, 매우 큼) |
| **is_bold** | `true` | 굵은 텍스트 |
| **line_count** | `1` | 줄 개수 |

### Bbox 분석

```
BBox: [x0, y0, x1, y1] = [70.70, 312.86, 524.30, 349.69]

의미:
  ├─ x0 (왼쪽): 70.70 pt      ← 페이지 왼쪽에서 70.70pt
  ├─ y0 (위):   312.86 pt     ← 페이지 위쪽에서 312.86pt
  ├─ x1 (오른쪽): 524.30 pt   ← 페이지 왼쪽에서 524.30pt
  ├─ y1 (아래):  349.69 pt    ← 페이지 위쪽에서 349.69pt
  ├─ 너비: 524.30 - 70.70 = 453.61pt ≈ 6.3 인치
  └─ 높이: 349.69 - 312.86 = 36.82pt ≈ 0.51 인치
```

### 위치 시각화

```
A4 문서 (595pt x 842pt)
┌─────────────────────────────────────────────┐
│ ← 70.70pt                                   │ 
│                                             │
│ (312.86pt)                                  │
│ ┌───────────────────────────────────────┐   │
│ │ 부표1. 현장점검 수행 및 평가기준       │   │ (36.82pt 높이)
│ │ (여기서부터 349.69pt까지)            │   │
│ └───────────────────────────────────────┘   │
│                 ↑                           │
│            524.30pt                         │
│                                             │
└─────────────────────────────────────────────┘
```

### 판정 기준

✓ **제목 판정 이유:**
- 폰트 크기: **32.02pt** (평균 14.5pt의 약 2.2배)
- 굵기: **Bold** 표시됨
- 페이지 상단에 위치 (중요한 위치)
- 문서 제목으로 적절한 내용

```json
{
  "type": "table",
```

### 상세 분석

| 속성 | 값 | 설명 |
|------|-----|------|
| **type** | `"table"` | 요소 타입: 표 |
| **page_num** | `1` | 페이지 번호 |
| **bbox** | `[165.15, 510.32, 430.11, 606.59]` | 표의 위치와 크기 |
| **rows** | `[ [...], [...], ... ]` | 행 데이터 배열 |
| **Row Count** | `5` | 5개 행 |
| **Column Count** | `4` | 4개 열 |
| **Total Cells** | `20` | 5 × 4 = 20개 셀 |

### 표 구조

```
Table 1: 5 행 × 4 열

┌────────┬────────┬────────┬────────┐
│Row 0   │Row 0   │Row 0   │Row 0   │
│Col 0   │Col 1   │Col 2   │Col 3   │
├────────┼────────┼────────┼────────┤
│Row 1   │Row 1   │Row 1   │Row 1   │
│Col 0   │Col 1   │Col 2   │Col 3   │
├────────┼────────┼────────┼────────┤
│Row 2   │Row 2   │Row 2   │Row 2   │
│Col 0   │Col 1   │Col 2   │Col 3   │
├────────┼────────┼────────┼────────┤
│Row 3   │Row 3   │Row 3   │Row 3   │
│Col 0   │Col 1   │Col 2   │Col 3   │
├────────┼────────┼────────┼────────┤
│Row 4   │Row 4   │Row 4   │Row 4   │
│Col 0   │Col 1   │Col 2   │Col 3   │
└────────┴────────┴────────┴────────┘
```

### 셀 구조 상세

**Row 0의 모든 셀:**
```json
[
  {"row": 0, "col": 0, "text": ""},
  {"row": 0, "col": 1, "text": ""},
  {"row": 0, "col": 2, "text": ""},
  {"row": 0, "col": 3, "text": ""}
]
```

**각 셀 정보:**
- `row`: 행 인덱스 (0부터 시작)
- `col`: 열 인덱스 (0부터 시작)
- `text`: 셀의 텍스트 내용 (이 표의 경우 모두 비어있음 → 이미지 형태)

### Bbox 분석

```
표 위치와 크기:
  └─ 왼쪽(x0): 165.15 pt
  └─ 위(y0):   510.32 pt
  └─ 오른쪽(x1): 430.11 pt
  └─ 아래(y1):  606.59 pt
  
  너비: 430.11 - 165.15 = 264.96 pt
  높이: 606.59 - 510.32 = 96.27 pt
```

### 특징

⚠️ **텍스트 없음 (0개 셀)**
- 모든 셀의 `text` 값이 빈 문자열
- 이유: **PDF의 표가 이미지 형태**로 스캔됨
- 해결방안: OCR(광학 문자 인식) 필요

## 📌 ELEMENT 3: PARAGRAPH (문단)

### JSON 구조

```json
{
  "type": "paragraph",
  "page_num": 1,
  "bbox": [189.70, 517.89, 414.90, 597.81],
  "text": "표준번호 I-AGG-0301-030-A01 개정번호 개정일자",
  "font_size": 13.34,
  "is_bold": true,
  "line_count": 4
}
```

### 상세 분석

| 속성 | 값 | 설명 |
|------|-----|------|
| **type** | `"paragraph"` | 요소 타입: 문단 |
| **page_num** | `1` | 페이지 번호 |
| **bbox** | `[189.70, 517.89, 414.90, 597.81]` | 문단의 위치 |
| **text** | `"표준번호 I-AGG-0301-030-A01 ..."` | 본문 텍스트 |
| **font_size** | `13.34` | 폰트 크기 (중간 크기) |
| **is_bold** | `true` | 굵은 텍스트 |
| **line_count** | `4` | 4개 줄로 구성 |

### Bbox 분석

```
문단 위치와 크기:
  ├─ 왼쪽(x0): 189.70 pt
  ├─ 위(y0):   517.89 pt
  ├─ 오른쪽(x1): 414.90 pt
  ├─ 아래(y1):  597.81 pt
  │
  ├─ 너비: 414.90 - 189.70 = 225.20 pt
  ├─ 높이: 597.81 - 517.89 = 79.91 pt (약 1.11인치)
  └─ 높이/line_count = 79.91 / 4 ≈ 20pt/줄
```

### 위치 관계

```
Table 1과 Paragraph의 Y 좌표 비교:

Table 1의 아래:    606.59pt
                    ↓ (약 -88.7pt 겹침)
Paragraph의 위:    517.89pt
Paragraph의 아래:  597.81pt
                    ↓ (약 119.3pt)
Table 2의 위:      717.12pt

→ 표와 문단이 Y 축에서 겹쳐있음 (같은 공간에 존재)
  이는 복잡한 레이아웃의 문서를 나타냄
```

### 판정 기준

✓ **문단 판정 이유:**
- 폰트 크기: **13.34pt** (헤딩 아님)
- 여러 줄(4줄)로 구성
- 문서 메타 정보 포함
- 제목도 목록도 아님

## 🎯 주요 발견 사항

### 1. 요소 배치의 복잡성
```
Paragraph의 범위:  Y = 517.89 ~ 597.81
Table 1의 범위:    Y = 510.32 ~ 606.59
                    ↑ 겹쳐있음!
```
- 문단과 표 1이 Y 축에서 겹쳐있음
- 복잡한 PDF 레이아웃

### 2. 이미지 형태의 표
```
Table 1: 0/20 셀에 텍스트
Table 2: 0/36 셀에 텍스트
→ OCR 필요
```

### 3. 타입별 특징
- **Heading**: 명확한 문서 제목 (32pt, Bold)
- **Paragraph**: 메타데이터 정보 (13pt, Bold, 4줄)
- **Table**: 그리드 구조 완벽 인식 (행/열 정보 있음, 텍스트 없음)
