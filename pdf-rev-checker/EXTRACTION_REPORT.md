### 1️⃣ 제목 (Heading) - 판정 기준

**기준:**
```
폰트 크기 >= 평균 폰트 크기 × 1.15  OR  굵게(Bold) 표시
```

**데이터 검증:**
```
평균 크기: 14.5pt
범위: 10.1 ~ 32.0pt (n=5)
```

**추출 예시:**
```json
{
  "type": "heading",
  "text": "부표1. 현장점검 수행 및 평가기준",
  "font_size": 32.02,
  "is_bold": true,
  "page_num": 1,
  "bbox": [70.70, 312.86, 524.30, 349.69]
}
```

**특징:**
- 폰트 크기 32pt (매우 큼)
- 굵게 표시됨
- 한 줄로 표시됨
- 페이지 상단에 위치

**데이터 검증:**

**특징:**

### 3️⃣ 목록 (List) - 판정 기준

**기준:**
```
다음 패턴 중 하나로 시작:
- 숫자: 1. 2. 3. 또는 1) 2) 3)
- 알파벳: a. b. c. 또는 A) B) C)
- 글머리: -, *, •, ○ 등
- 들여쓰기 + 위 기호
```

**정규식:**
```python
r"^\d+[\.\)]\s"           # 1. 2. 3.
r"^[a-zA-Z][\.\)]\s"      # a. b. c.
r"^[\•○\-\*]\s"           # 글머리
r"^\s+([\•○\-\*]|[0-9]+[\.\)])" # 들여쓰기
```

**추출 현황:**
- 목록 요소 1개 검출 (page 2)
- 주로 단일 항목으로 나타남

## 📍 Bbox (Bounding Box) 정보

### 형식
```
[x0, y0, x1, y1]
```

### 의미
| 값 | 설명 |
|----|------|
| **x0** | 요소의 왼쪽 시작 위치 (포인트) |
| **y0** | 요소의 위쪽 시작 위치 (포인트) |
| **x1** | 요소의 오른쪽 끝 위치 (포인트) |
| **y1** | 요소의 아래쪽 끝 위치 (포인트) |

### 단위
- **PDF 포인트** (1/72 인치)
- 일반 화면: 96 DPI
- PDF 표준: 72 DPI

### 좌표계
```
(0, 0) ────────────── x ──────────────>
  │
  │  PDF 문서
  │  ┌─────────────────────────┐
  │  │  요소                    │
  │  │  [x0, y0, x1, y1]       │
  │  └─────────────────────────┘
  │
  y
  ↓
```

### 예시 - 제목의 Bbox
```
부표1. 현장점검 수행 및 평가기준
bbox: [70.70, 312.86, 524.30, 349.69]

의미:
- 왼쪽(x0): 70.70pt
- 위쪽(y0): 312.86pt
- 오른쪽(x1): 524.30pt
- 아래쪽(y1): 349.69pt
- 너비: 524.30 - 70.70 = 453.60pt ≈ 6.3인치
- 높이: 349.69 - 312.86 = 36.83pt ≈ 0.51인치
```

## 🎯 사용 예제

### Python에서 직접 사용
```python
from pdf_extractor import extract_structured_pdf

# PDF 추출
data, json_path = extract_structured_pdf("file.pdf")

# 메타데이터 접근
print(data["metadata"]["filename"])
print(f"총 {data['metadata']['total_pages']}페이지")

# 페이지별 요소 접근
for page in data["content"]:
    print(f"\n페이지 {page['page_num']}:")
    
    for element in page["elements"]:
        if element["type"] == "heading":
            print(f"  [제목] {element['text']}")
        elif element["type"] == "table":
            print(f"  [표] {len(element['rows'])}행 × {len(element['rows'][0])}열")
        else:
            print(f"  [{element['type']}] {element['text'][:50]}...")
```
